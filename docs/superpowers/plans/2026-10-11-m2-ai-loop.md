# ChatSCAD M2 — AI Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Describe a part in a chat column, have a model from any saved provider profile write or edit the OpenSCAD, watch it compile through the existing render loop with automatic error fixing, and see the token count and cost of every reply, without touching the code.

**Architecture:** Two adapters (`fetch` + a small SSE parser for OpenAI-compatible endpoints; the official `@anthropic-ai/sdk` for Anthropic) implement one `LlmProvider` interface. `generateCode` turns one streamed reply into code (full file or SEARCH/REPLACE edits, with one full-file retry), and `runTurn` applies it through `useAppStore.setCode`, waits for the existing `RenderController` result via `awaitRender`, and sends compiler errors back up to `settings.autoFixAttempts` times. Provider profiles, settings and usage rows live in IndexedDB (Dexie) behind small repository modules; two Zustand stores (`providersStore`, `chatStore`) hold the UI state, and the workbench gains the 360 px chat column and a full-page settings view.

**Tech Stack:** M1 stack (Vite, React 19, TypeScript strict, Tailwind v4, Zustand, CodeMirror 6, react-three-fiber, Vitest + Testing Library, Playwright) plus `dexie@4.4.6`, `@anthropic-ai/sdk@0.133.0`, and `fake-indexeddb@6.2.5` (dev). No other new dependency.

**Spec:** [`docs/SPEC.md`](../../SPEC.md) Milestone 2 ("AI loop"), "AI provider layer", "Token and cost tracking", "Security". Decisions, scope and the **Shared contracts** this plan must keep: [`docs/superpowers/specs/2026-10-11-m2-m5-design.md`](../specs/2026-10-11-m2-m5-design.md) (D1–D6, D13, D14, "M2 — AI loop").

**Design sources:** [`design/screens/`](../../../design/screens/) `Main` (chat column: pane head with cost caption, `pc-msg` user/assistant bubbles, meta line with turn chip, model and "1,180 tok · $0.006", composer with `pc-model` and Send), `FirstRun` (info callout "Connect an AI model to start", "Try asking for" suggestions, disabled "No model" picker and Send), `CompileError` (failed chip, error callout, "Auto-fix 1 of 2" busy pill, **Stop auto-fix**, **Back to vN**), `Providers` (settings page: header with **Back to project**, section nav, profile list with status pills, "This month" totals, profile form with CORS callout, capability switches, **Test connection**, **Edit price table**). ## Global Constraints

From the spec:

- No backend and no proxy: providers are called from the browser; "A proxy can be added later behind the same interface."
- "One `LlmProvider` interface (`listModels`, `streamChat`, capability flags) … the rest of the app never sees provider differences."
- OpenAI-compatible profiles: "User sets base URL, key, model; models from `GET /models` with manual fallback."
- "A 'Test connection' button sends a tiny request and reports CORS, auth and model errors in plain words." Local servers need "their allowed-origins setting (e.g. Ollama's `OLLAMA_ORIGINS`)".
- System prompt: "valid OpenSCAD only, millimetres, top-level parameters with Customizer comments, named modules per logical part, no external libraries unless enabled."
- "First generation returns a full file in one fenced block." "Follow-up edits return search/replace blocks … the app falls back to requesting a full file if a block fails to apply."
- "If the result fails to compile, the app sends stderr back automatically, up to N attempts (default 2)."
- Usage: "streaming requests ask for usage in the final chunk where supported; OpenRouter also reports cost directly"; "Cost is computed from provider-reported prices when available, else from an editable per-model price table."
- "A model picker sits next to the send button, so the model can change per message."
- Keys: "keys in IndexedDB, shown masked, never logged or included in project exports." "Recommend provider keys with spending limits."
- "Model output is untrusted … never `eval`, never rendered as HTML. Markdown in chat is sanitized." M2 renders replies as React text nodes, with backtick spans split into `<code>` elements by a string splitter, nothing else.
- CSP is unchanged: `connect-src 'self' https: http://localhost:* http://127.0.0.1:*` (already in `build/csp.ts`).

## Review Focus

1. **The editor echoes the AI's code back as a "manual" edit.** `CodeEditor` dispatches the new value and its update listener calls `setCode(code)` again. Expected: `setCode` with unchanged code is a no-op that keeps `codeSource === 'ai'`, so the "stop the turn on manual edits" guard never fires on the model's own code and the turn finishes. *Pinned in Task 9 (store test "an unchanged setCode keeps the source") and Task 17 (App test sends a prompt through the real editor and asserts no "Stopped" note).*
2. **The user types in the editor while a turn is streaming or waiting for its render.** `awaitRender` would wait forever for code that will never render. Expected: the turn aborts at once, the chat shows "Stopped: you edited the code.", the user's text stays in the editor, the composer is usable again. *Pinned in Task 12 (sendPrompt test "a manual edit stops the turn").*
3. **A SEARCH block that does not match exactly, or matches twice.** Expected: nothing is applied partially; one automatic follow-up asks for the full file; if that also fails the reply shows its prose with no code change; `$fn`, `$&` and `$$` in replacements are kept literally. *Pinned in Task 7 (`applyEdits` tests) and Task 10 (`generateCode` retry tests).*
4. **A local server blocked by CORS** (Ollama without `OLLAMA_ORIGINS`, LM Studio without CORS on). `fetch` rejects with a `TypeError`. Expected: Test connection shows "Ollama blocked the request from this page (CORS)" with `OLLAMA_ORIGINS=<this site's origin> ollama serve`, the profile row says **Blocked**, a chat turn shows the same callout in the reply, nothing throws. *Pinned in Task 6 (`describeProviderError` tests) and Task 15 (ProfileForm test).*
5. **An OpenAI-compatible server that rejects `stream_options` or `max_tokens`** (older vLLM and LM Studio builds; OpenAI reasoning models that want `max_completion_tokens`). Expected: one retry with the parameter dropped or renamed, then a normal stream; any other 400 is reported as is. *Pinned in Task 3 (adapter retry tests).*

// @vitest-environment node
import { parseSse, type SseEvent } from './sse'

const enc = new TextEncoder()

function streamOf(...chunks: Array<string | Uint8Array>): ReadableStream<Uint8Array> {
  return new ReadableStream<Uint8Array>({
    start(controller) {
      for (const c of chunks) controller.enqueue(typeof c === 'string' ? enc.encode(c) : c)
      controller.close()
    },
  })
}

async function collect(body: ReadableStream<Uint8Array>): Promise<SseEvent[]> {
  const out: SseEvent[] = []
  for await (const e of parseSse(body)) out.push(e)
  return out
}

it('yields one event per blank-line-terminated block, with the default event name', async () => {
  expect(await collect(streamOf('data: {"a":1}\n\ndata: [DONE]\n\n'))).toEqual([
    { event: 'message', data: '{"a":1}' },
    { event: 'message', data: '[DONE]' },
  ])
})

it('keeps the event field and joins multi-line data with newlines', async () => {
  expect(await collect(streamOf('event: message_start\ndata: one\ndata: two\n\n'))).toEqual([
    { event: 'message_start', data: 'one\ntwo' },
  ])
})

it('reassembles lines split across chunks, including a split multi-byte character', async () => {
  const bytes = enc.encode('ta: 20 × 20\n\n')
  const cut = bytes.indexOf(0xc3) + 1 // inside the two-byte "×"
  expect(await collect(streamOf('da', bytes.slice(0, cut), bytes.slice(cut)))).toEqual([
    { event: 'message', data: '20 × 20' },
  ])
})

it('accepts CRLF and CR line endings, also when \\r\\n is split between chunks', async () => {
  expect(await collect(streamOf('data: a\r', '\n\r\ndata: b\r\rdata: c\n\n'))).toEqual([
    { event: 'message', data: 'a' },
    { event: 'message', data: 'b' },
    { event: 'message', data: 'c' },
  ])
})

it('ignores comment lines such as OpenRouter keep-alives', async () => {
  expect(await collect(streamOf(': OPENROUTER PROCESSING\n\ndata: x\n\n'))).toEqual([{ event: 'message', data: 'x' }])
})

it('flushes a final event that has no trailing blank line', async () => {
  expect(await collect(streamOf('data: last'))).toEqual([{ event: 'message', data: 'last' }])
})

it('cancels the body when the consumer stops early', async () => {
  const cancel = vi.fn()
  const body = new ReadableStream<Uint8Array>({
    start(c) {
      c.enqueue(enc.encode('data: 1\n\ndata: 2\n\n'))
    },
    cancel,
  })
  for await (const e of parseSse(body)) {
    expect(e.data).toBe('1')
    break
  }
  expect(cancel).toHaveBeenCalled()
})

export function joinUrl(base: string, path: string): string {
  return `${base.trim().replace(/\/+$/, '')}/${path.replace(/^\/+/, '')}`
}

export function hostOf(url: string): string {
  try {
    return new URL(url).host
  } catch {
    return url.trim() || 'the provider'
  }
}

export function portOf(url: string): string {
  try {
    return new URL(url).port
  } catch {
    return ''
  }
}

/** True for servers on this computer (Ollama, LM Studio, llama.cpp …). */
export function isLocalBaseUrl(url: string): boolean {
  try {
    const host = new URL(url).hostname
    return host === 'localhost' || host === '127.0.0.1' || host === '[::1]' || host.endsWith('.localhost')
  } catch {
    return false
  }
}

`src/ai/sse.ts`:

```ts
export interface SseEvent {
  event: string
  data: string
}

/** Parses a text/event-stream body (WHATWG rules: data/event fields, comments, CR/LF/CRLF, final flush). */
export async function* parseSse(body: ReadableStream<Uint8Array>): AsyncGenerator<SseEvent> {
  const reader = body.getReader()
  const decoder = new TextDecoder()
  let buffer = ''
  let event = ''
  let data: string[] = []
  let finished = false

  const takeLines = (final: boolean): string[] => {
    const lines: string[] = []
    for (;;) {
      const match = /\r\n|\r|\n/.exec(buffer)
      if (!match) return lines
      // A lone \r at the very end may be the first half of \r\n: wait for the next chunk.
      if (match[0] === '\r' && match.index === buffer.length - 1 && !final) return lines
      lines.push(buffer.slice(0, match.index))
      buffer = buffer.slice(match.index + match[0].length)
    }
  }

  const feed = (line: string): SseEvent | null => {
    if (line === '') {
      if (data.length === 0) {
        event = ''
        return null
      }
      const out = { event: event || 'message', data: data.join('\n') }
      event = ''
      data = []
      return out
    }
    if (line.startsWith(':')) return null
    const colon = line.indexOf(':')
    const field = colon < 0 ? line : line.slice(0, colon)
    let value = colon < 0 ? '' : line.slice(colon + 1)
    if (value.startsWith(' ')) value = value.slice(1)
    if (field === 'data') data.push(value)
    else if (field === 'event') event = value
    return null
  }

  try {
    for (;;) {
      const { value, done } = await reader.read()
      buffer += done ? decoder.decode() : decoder.decode(value, { stream: true })
      for (const line of takeLines(done)) {
        const e = feed(line)
        if (e) yield e
      }
      if (done) break
    }
    finished = true
    if (buffer !== '') {
      const e = feed(buffer)
      if (e) yield e
    }
    const last = feed('')
    if (last) yield last
  } finally {

import type { ModelInfo, ModelPrice, Usage } from './types'
import { isLocalBaseUrl } from './url'

export function computeCost(
  usage: Usage,
  price: ModelPrice | undefined,
): { cost: number | null; costSource: 'provider' | 'price-table' | null } {
  if (typeof usage.costUsd === 'number' && Number.isFinite(usage.costUsd)) return { cost: usage.costUsd, costSource: 'provider' }
  if (price) {
    return {
      cost: (usage.inputTokens * price.inputPerMTok + usage.outputTokens * price.outputPerMTok) / 1_000_000,
      costSource: 'price-table',
    }
  }
  return { cost: null, costSource: null }
}

export interface PricedProfile {
  baseUrl: string
  priceTable: Record<string, ModelPrice>
  cachedModels: ModelInfo[]
}

const FREE: ModelPrice = { inputPerMTok: 0, outputPerMTok: 0 }

/** The user's price table wins, then the provider's listed price; a server on this computer costs nothing. */
export function priceFor(profile: PricedProfile, model: string): ModelPrice | undefined {
  return (
    profile.priceTable[model] ??
    profile.cachedModels.find((m) => m.id === model)?.price ??
    (isLocalBaseUrl(profile.baseUrl) ? FREE : undefined)
  )
}

import { parseSse } from './sse'
import {
  DEFAULT_MAX_TOKENS,
  ProviderError,
  type ChatEvent,
  type ChatRequest,
  type LlmMessage,
  type LlmProvider,
  type ModelInfo,
  type ModelPrice,
  type ProviderErrorKind,
  type Usage,
} from './types'
import { joinUrl, type FetchLike } from './url'

export interface OpenAiCompatibleOptions {
  baseUrl: string
  apiKey: string
  /** Profile capability; false sends one plain request (for servers that cannot stream). Default true. */
  streaming?: boolean
  fetch?: FetchLike
}

type Body = Record<string, unknown>

interface OpenAiUsage {
  prompt_tokens?: number
  completion_tokens?: number
  cost?: number
}
interface OpenAiChunk {
  choices?: Array<{ delta?: { content?: string | null } }>
  usage?: OpenAiUsage | null
  error?: unknown
}
interface OpenAiCompletion {
  choices?: Array<{ message?: { content?: string | null } }>
  usage?: OpenAiUsage | null
}
interface OpenAiModel {
  id?: unknown
  name?: unknown
  pricing?: { prompt?: unknown; completion?: unknown }
}

export function kindForStatus(status: number): ProviderErrorKind {
  if (status === 401 || status === 403) return 'auth'
  if (status === 404) return 'not-found'
  if (status === 429) return 'rate-limit'
  if (status >= 500) return 'server'
  return 'bad-request'
}

function messageFrom(body: string): string {
  try {
    const parsed = JSON.parse(body) as { error?: { message?: unknown } | string; message?: unknown; detail?: unknown }
    const m = typeof parsed.error === 'string' ? parsed.error : (parsed.error?.message ?? parsed.message ?? parsed.detail)
    if (typeof m === 'string' && m.trim()) return m.trim()
  } catch {
    // not JSON: fall through to the raw text
  }
  return body.trim().slice(0, 300)
}

/** One retry-able fix per call: the parameter the error names is dropped or renamed. */
export function relaxRequest(body: Body, errorText: string): Body | null {
  const next: Body = { ...body }
  if ('stream_options' in next && /stream_options/.test(errorText)) {
    delete next.stream_options
    return next
  }
  if ('max_tokens' in next && /max_completion_tokens/.test(errorText)) {
    next.max_completion_tokens = next.max_tokens
    delete next.max_tokens
    return next
  }
  if ('max_tokens' in next && /max_tokens/.test(errorText)) {
    delete next.max_tokens
    return next
  }
  return null
}

function toUsage(u: OpenAiUsage): Usage {
  return {
    inputTokens: u.prompt_tokens ?? 0,
    outputTokens: u.completion_tokens ?? 0,
    ...(typeof u.cost === 'number' ? { costUsd: u.cost } : {}),
  }
}

function perMillion(value: unknown): number | null {
  const n = Number(value)
  return Number.isFinite(n) && n >= 0 && value !== '' && value !== null && value !== undefined
    ? Number((n * 1_000_000).toPrecision(12))
    : null
}

function toPrice(pricing: OpenAiModel['pricing']): ModelPrice | undefined {
  if (!pricing) return undefined
  const input = perMillion(pricing.prompt)
  const output = perMillion(pricing.completion)
  return input === null || output === null ? undefined : { inputPerMTok: input, outputPerMTok: output }
}

function toOpenAiMessage(m: LlmMessage): Body {
  if (typeof m.content === 'string') return { role: m.role, content: m.content }
  return {
    role: m.role,
    content: m.content.map((p) =>
      p.type === 'text'
        ? { type: 'text', text: p.text }
        : { type: 'image_url', image_url: { url: `data:${p.mediaType};base64,${p.data}` } },
    ),
  }
}

function transportError(err: unknown, url: string, signal?: AbortSignal): ProviderError {
  if (signal?.aborted || (err instanceof DOMException && err.name === 'AbortError')) {
    return new ProviderError('aborted', 'The request was stopped')
  }
  return new ProviderError('network', `Couldn't reach ${url}: ${errorMessage(err)}`)
}

export function createOpenAiCompatibleProvider(opts: OpenAiCompatibleOptions): LlmProvider {
  // Wrapped so window.fetch is never called unbound ("Illegal invocation").
  const doFetch: FetchLike = opts.fetch ?? ((input, init) => fetch(input, init))
  const streaming = opts.streaming ?? true

  const headers = (json: boolean): Record<string, string> => {
    const h: Record<string, string> = json ? { 'Content-Type': 'application/json' } : {}
    if (opts.apiKey.trim()) h.Authorization = `Bearer ${opts.apiKey.trim()}`
    return h
  }

  async function send(url: string, init: RequestInit, signal?: AbortSignal): Promise<Response> {
    try {
      return await doFetch(url, { ...init, signal })
    } catch (err) {
      throw transportError(err, url, signal)
    }
  }

  async function failure(res: Response): Promise<{ error: ProviderError; text: string }> {
    const text = await res.text().catch(() => '')
    return { error: new ProviderError(kindForStatus(res.status), messageFrom(text) || `HTTP ${res.status}`, res.status), text }
  }

  async function postChat(url: string, body: Body, signal?: AbortSignal): Promise<Response> {
    for (let attempt = 0; ; attempt++) {
      const res = await send(url, { method: 'POST', headers: headers(true), body: JSON.stringify(body) }, signal)
      if (res.ok) return res
      const { error, text } = await failure(res)
      const relaxed = res.status === 400 && attempt < 3 ? relaxRequest(body, text) : null
      if (!relaxed) throw error
      body = relaxed
    }
  }

  return {
    async listModels(signal) {
      const url = joinUrl(opts.baseUrl, 'models')
      const res = await send(url, { method: 'GET', headers: headers(false) }, signal)
      if (!res.ok) throw (await failure(res)).error
      let parsed: { data?: unknown }
      try {
        parsed = (await res.json()) as { data?: unknown }
      } catch (err) {
        if (signal?.aborted) throw transportError(err, url, signal)
        throw new ProviderError('server', `${url} did not answer with a model list`)
      }
      const rows = Array.isArray(parsed.data) ? (parsed.data as OpenAiModel[]) : []
      const models = rows.flatMap((m): ModelInfo[] => {
        if (typeof m.id !== 'string' || m.id === '') return []
        const price = toPrice(m.pricing)
        return [{ id: m.id, ...(typeof m.name === 'string' && m.name !== m.id ? { name: m.name } : {}), ...(price ? { price } : {}) }]
      })
      return models.sort((a, b) => a.id.localeCompare(b.id))
    },

    async *streamChat(req: ChatRequest, signal?: AbortSignal): AsyncGenerator<ChatEvent> {
      const url = joinUrl(opts.baseUrl, 'chat/completions')
      const body: Body = {
        model: req.model,
        messages: [{ role: 'system', content: req.system }, ...req.messages.map(toOpenAiMessage)],
        max_tokens: req.maxTokens ?? DEFAULT_MAX_TOKENS,
        ...(req.temperature !== undefined ? { temperature: req.temperature } : {}),
        ...(streaming ? { stream: true, stream_options: { include_usage: true } } : {}),
      }
      const res = await postChat(url, body, signal)
      let usage: Usage = { inputTokens: 0, outputTokens: 0 }

      if (!streaming) {
        let reply: OpenAiCompletion
        try {
          reply = (await res.json()) as OpenAiCompletion
        } catch (err) {
          throw transportError(err, url, signal)
        }
        const text = reply.choices?.[0]?.message?.content ?? ''
        if (text) yield { type: 'text', delta: text }
        if (reply.usage) usage = toUsage(reply.usage)
        yield { type: 'usage', usage }
        return
      }

      if (!res.body) throw new ProviderError('server', `${url} answered without a body`)
      try {
        for await (const event of parseSse(res.body)) {
          if (event.data === '[DONE]') break
          let chunk: OpenAiChunk
          try {
            chunk = JSON.parse(event.data) as OpenAiChunk
          } catch {
            continue
          }
          if (chunk.error) throw new ProviderError('server', messageFrom(JSON.stringify(chunk)))
          const text = chunk.choices?.[0]?.delta?.content
          if (typeof text === 'string' && text !== '') yield { type: 'text', delta: text }
          if (chunk.usage) usage = toUsage(chunk.usage)
        }
      } catch (err) {
        if (err instanceof ProviderError) throw err
        throw transportError(err, url, signal)
      }
      yield { type: 'usage', usage }
    },
  }
}

import Anthropic from '@anthropic-ai/sdk'
import { DEFAULT_MAX_TOKENS, ProviderError, type ChatEvent, type ChatRequest, type LlmMessage, type LlmProvider, type ModelInfo, type Usage } from './types'
import type { FetchLike } from './url'

export interface AnthropicOptions {
  baseUrl: string
  apiKey: string
  fetch?: FetchLike
  /** SDK retries for 408/409/429/5xx and connection errors. Default 2; tests pass 0. */
  maxRetries?: number
}

function apiMessage(err: InstanceType<typeof Anthropic.APIError>): string {
  const body = err.error as { error?: { message?: unknown } } | undefined
  const nested = body?.error?.message
  return typeof nested === 'string' && nested.trim() ? nested.trim() : err.message
}

export function toProviderError(err: unknown, signal?: AbortSignal): ProviderError {
  if (err instanceof ProviderError) return err
  if (err instanceof Anthropic.APIUserAbortError || signal?.aborted) return new ProviderError('aborted', 'The request was stopped')
  if (err instanceof Anthropic.APIConnectionError) return new ProviderError('network', err.message)
  if (err instanceof Anthropic.AuthenticationError || err instanceof Anthropic.PermissionDeniedError) {
    return new ProviderError('auth', apiMessage(err), err.status)
  }
  if (err instanceof Anthropic.NotFoundError) return new ProviderError('not-found', apiMessage(err), err.status)
  if (err instanceof Anthropic.RateLimitError) return new ProviderError('rate-limit', apiMessage(err), err.status)
  if (err instanceof Anthropic.BadRequestError) return new ProviderError('bad-request', apiMessage(err), err.status)
  if (err instanceof Anthropic.APIError) {
    const status = typeof err.status === 'number' ? err.status : undefined
    return new ProviderError(status !== undefined && status >= 500 ? 'server' : 'bad-request', apiMessage(err), status)
  }
  return new ProviderError('server', err instanceof Error ? err.message : String(err))
}

function toAnthropicMessage(m: LlmMessage): Anthropic.MessageParam {
  if (typeof m.content === 'string') return { role: m.role, content: m.content }
  return {
    role: m.role,
    content: m.content.map((p): Anthropic.TextBlockParam | Anthropic.ImageBlockParam =>
      p.type === 'text'
        ? { type: 'text', text: p.text }
        : { type: 'image', source: { type: 'base64', media_type: p.mediaType, data: p.data } },
    ),
  }
}

export function createAnthropicProvider(opts: AnthropicOptions): LlmProvider {
  let client: Anthropic | null = null
  const getClient = (): Anthropic => {
    if (!opts.apiKey.trim()) throw new ProviderError('auth', 'This profile has no API key')
    client ??= new Anthropic({
      apiKey: opts.apiKey.trim(),
      baseURL: opts.baseUrl.trim().replace(/\/+$/, '') || undefined,
      dangerouslyAllowBrowser: true,
      maxRetries: opts.maxRetries ?? 2,
      ...(opts.fetch ? { fetch: opts.fetch } : {}),
    })
    return client
  }

  return {
    async listModels(signal) {
      const models: ModelInfo[] = []
      try {
        for await (const m of getClient().models.list({ limit: 100 }, { signal })) models.push({ id: m.id, name: m.display_name })
      } catch (err) {
        throw toProviderError(err, signal)
      }
      return models
    },

    async *streamChat(req: ChatRequest, signal?: AbortSignal): AsyncGenerator<ChatEvent> {
      const usage: Usage = { inputTokens: 0, outputTokens: 0 }
      try {
        // No `thinking` and no `temperature`: current Claude models reject sampling parameters.
        const stream = getClient().messages.stream(
          {
            model: req.model,
            max_tokens: req.maxTokens ?? DEFAULT_MAX_TOKENS,
            system: req.system,
            messages: req.messages.map(toAnthropicMessage),
          },
          { signal },
        )
        for await (const event of stream) {
          if (event.type === 'message_start') {
            usage.inputTokens = event.message.usage.input_tokens
            usage.outputTokens = event.message.usage.output_tokens
          } else if (event.type === 'content_block_delta' && event.delta.type === 'text_delta') {
            yield { type: 'text', delta: event.delta.text }
          } else if (event.type === 'message_delta') {
            usage.outputTokens = event.usage.output_tokens
            if (typeof event.usage.input_tokens === 'number') usage.inputTokens = event.usage.input_tokens
          }
        }
      } catch (err) {
        throw toProviderError(err, signal)
      }
      yield { type: 'usage', usage }
    },
  }
}

function sentence(text: string): string {
  const t = text.trim()
  if (t === '') return ''
  return /[.?!…]$/.test(t) ? t : `${t}.`
}

function join(...parts: string[]): string {
  return parts.filter((p) => p !== '').join(' ')
}

function siteOrigin(): string {
  return typeof location !== 'undefined' ? location.origin : 'https://your-chatscad-site'
}

export function describeProviderError(err: unknown, baseUrl: string): { title: string; body: string } {
  const host = hostOf(baseUrl)
  if (!(err instanceof ProviderError)) {
    return { title: `Something went wrong talking to ${host}`, body: sentence(errorMessage(err)) }
  }
  const detail = sentence(err.message)
  switch (err.kind) {
    case 'network': {
      const origin = siteOrigin()
      if (isLocalBaseUrl(baseUrl)) {
        if (portOf(baseUrl) === '11434') {
          return {
            title: 'Ollama blocked the request from this page (CORS)',
            body: `Allow this site, then restart Ollama: OLLAMA_ORIGINS=${origin} ollama serve. If Ollama isn't running, start it first.`,

          return {
            title: 'LM Studio blocked the request from this page (CORS)',
            body: "Turn on CORS in LM Studio's server settings, start the server, then try again.",
          }
        }
        return { title: `Couldn't reach ${host}`, body: `Check that the server on ${host} is running and allows requests from ${origin} (CORS).` }
      }
      return {
        title: `Couldn't reach ${host}`,
        body: `Check the base URL and your connection. If both are right, ${host} doesn't accept requests from a web page (CORS), and ChatSCAD has no server to relay them.`,
      }
    }
    case 'auth':
      return { title: `${host} rejected the API key`, body: join(detail, 'Check the key in Settings › AI providers.') }

        title: `${host} doesn't know this model or address`,
        body: join(detail, 'Pick another model, or check that the base URL ends where the API starts (for example …/v1).'),
      }
    case 'bad-request':
      if (/\bmodel\b/i.test(err.message)) {

`src/ai/edits.ts`:

```ts
export interface SearchReplace {
  search: string
  replace: string
}

export type ParsedReply =
  | { kind: 'full'; code: string; prose: string }
  | { kind: 'edits'; edits: SearchReplace[]; prose: string }
  | { kind: 'none'; prose: string }

export type ApplyResult = { ok: true; code: string } | { ok: false; failedIndex: number }

const BLOCK = /^<{7} SEARCH[^\S\n]*\n([\s\S]*?)^={7}[^\S\n]*\n([\s\S]*?)^>{7} REPLACE[^\S\n]*$/gm
const FENCE = /^```[^\S\n]*([\w+-]*)[^\n]*\n([\s\S]*?)^```[^\S\n]*$/gm
const EMPTY_FENCE = /^```[\w+-]*[^\S\n]*\n\s*^```[^\S\n]*$/gm

const lf = (s: string) => s.replace(/\r\n?/g, '\n')
const chomp = (s: string) => (s.endsWith('\n') ? s.slice(0, -1) : s)

function cleanProse(text: string): string {
  return text.replace(EMPTY_FENCE, '').replace(/\n{3,}/g, '\n\n').trim()
}

export function parseReply(text: string): ParsedReply {
  const src = lf(text)

  const edits: SearchReplace[] = []
  const withoutBlocks = src.replace(BLOCK, (_match, search: string, replace: string) => {
    edits.push({ search: chomp(search), replace: chomp(replace) })
    return ''
  })
  if (edits.length > 0) return { kind: 'edits', edits, prose: cleanProse(withoutBlocks) }

  const fences = [...src.matchAll(FENCE)].filter((f) => f[2].trim() !== '')
  const scad = fences.filter((f) => /^(openscad|scad)$/i.test(f[1]))
  const candidates = scad.length > 0 ? scad : fences.filter((f) => f[1] === '')
  const chosen = candidates.at(-1)
  if (!chosen) return { kind: 'none', prose: cleanProse(src) }

  let prose = src
  for (const f of candidates) prose = prose.replace(f[0], () => '')
  return { kind: 'full', code: chosen[2], prose: cleanProse(prose) }
}

/** Each search must match exactly once (after normalising CRLF); edits apply in order. */
export function applyEdits(code: string, edits: SearchReplace[]): ApplyResult {
  let out = lf(code)
  for (const [i, edit] of edits.entries()) {
    const search = lf(edit.search)
    if (search === '') return { ok: false, failedIndex: i }
    const at = out.indexOf(search)
    if (at < 0 || out.indexOf(search, at + 1) >= 0) return { ok: false, failedIndex: i }
    out = out.slice(0, at) + lf(edit.replace) + out.slice(at + search.length)
  }
  return { ok: true, code: out }
}
```

import type { RenderResult } from '../render/types'
import type { ContentPart, LlmMessage } from './types'

export interface PromptContext {
  code: string // current editor code ('' when empty)
  errors?: string // compiler errors for auto-fix
  libraries?: string[] // M3: enabled libraries
  selection?: { startLine: number; endLine: number; label: string } // M5: scoped edit
}

export const SYSTEM_PROMPT = `You are ChatSCAD's modelling assistant. You write OpenSCAD for parts that will be 3D printed.

Rules for the code:
- Write valid OpenSCAD only. Units are millimetres.
- Put every tunable dimension in a top-level variable with an OpenSCAD Customizer comment, for example \`width = 40; // [10:1:200]\`, and group the variables under \`/* [Group] */\` headings.
- Make one named module per logical part, and call the modules at the end of the file.
- Set $fn on round primitives (48 to 96 is usually enough) so previews stay fast.
- Never use import(), surface() or any file that is not in the code.

How to reply:
- Start with one or two short sentences that say what you made or changed. No headings and no list of every parameter.
- To write a whole file, put all of it in one \`\`\`openscad fenced block.
- To change the current file, use one or more SEARCH/REPLACE blocks instead of a fence:
<<<<<<< SEARCH
exact lines from the current file
=======
replacement lines
>>>>>>> REPLACE
- Each SEARCH must copy the current lines exactly, including indentation and comments, and must match only one place in the file. Keep blocks small and in file order.
- When you are asked to fix compiler errors, change only what is needed to make the file compile.`

export function buildSystemPrompt(ctx: PromptContext): string {
  const libraries =
    ctx.libraries && ctx.libraries.length > 0
      ? `Libraries available: ${ctx.libraries.join(', ')}. Include them with include <…> or use <…> only where they help.`
      : 'No external libraries are available: do not use include <…> or use <…>.'
  return `${SYSTEM_PROMPT}\n\n${libraries}`
}

/** Turns the chat history plus the new user text into provider messages, putting the current code and any errors into the final user message. */
export function buildMessages(history: LlmMessage[], userText: string | ContentPart[], ctx: PromptContext): LlmMessage[] {
  const empty = ctx.code.trim() === ''
  const fullFile = history.length === 0 || empty
  const parts: string[] = [
    empty ? 'The editor is empty.' : `Current main.scad:\n\`\`\`openscad\n${ctx.code.endsWith('\n') ? ctx.code : `${ctx.code}\n`}\`\`\``,
  ]
  if (ctx.errors && ctx.errors.trim() !== '') parts.push(`OpenSCAD reported these errors:\n\`\`\`text\n${ctx.errors.trim()}\n\`\`\``)
  parts.push(
    fullFile
      ? 'Reply with the complete file in one ```openscad block.'
      : 'Reply with SEARCH/REPLACE blocks against the current main.scad, or with the complete file in one ```openscad block if most of it changes.',
  )
  const context = parts.join('\n\n')
  const content: LlmMessage['content'] =
    typeof userText === 'string' ? `${context}\n\nRequest: ${userText}` : [{ type: 'text', text: `${context}\n\nRequest:` }, ...userText]
  return [...history, { role: 'user', content }]
}

const MAX_ERROR_CHARS = 4000

/** The compiler's own words for a failed render, for the auto-fix request. */
export function formatCompileErrors(result: RenderResult): string {
  if (result.ok) return ''
  const lines = result.logs.filter((l) => /^(ERROR|WARNING|Execution aborted)/.test(l.text)).map((l) => l.text)
  const text = lines.length > 0 ? lines.join('\n') : result.error
  return text.length > MAX_ERROR_CHARS ? `${text.slice(0, MAX_ERROR_CHARS)}\n…` : text
}
````

`src/render/awaitRender.ts`:

```ts
import { useAppStore, type AppState } from '../state/store'
import type { RenderResult } from './types'

const abortError = () => new DOMException('Stopped waiting for the render', 'AbortError')

function resultFor(state: AppState, code: string): RenderResult | null {
  return state.lastRender !== null && state.lastRender.code === code ? state.lastRender.result : null
}

/** Resolves with the first finished render of exactly `code` (including one already present). */
export function awaitRender(code: string, signal?: AbortSignal): Promise<RenderResult> {
  return new Promise<RenderResult>((resolve, reject) => {
    if (signal?.aborted) {
      reject(abortError())
      return
    }
    const present = resultFor(useAppStore.getState(), code)
    if (present) {
      resolve(present)
      return
    }
    const onAbort = () => {
      cleanup()
      reject(abortError())
    }
    const unsubscribe = useAppStore.subscribe((state) => {
      const result = resultFor(state, code)
      if (result) {
        cleanup()
        resolve(result)
      }
    })
    function cleanup() {
      unsubscribe()
      signal?.removeEventListener('abort', onAbort)
    }
    signal?.addEventListener('abort', onAbort, { once: true })
  })
}

import type { ChatRequest, LlmProvider, ModelInfo, Usage } from '../ai/types'

export interface ScriptedReply {
  text: string
  usage?: Usage
}

/** A fake LlmProvider that replays canned replies in order and records every request. */
export function scriptedProvider(...replies: Array<string | ScriptedReply | Error>) {
  const requests: ChatRequest[] = []
  const models: ModelInfo[] = []
  const provider: LlmProvider = {
    listModels: async () => models,
    async *streamChat(req) {
      requests.push(req)
      const next = replies.shift()
      if (next === undefined) throw new Error('scriptedProvider: no reply left')
      if (next instanceof Error) throw next
      const reply = typeof next === 'string' ? { text: next } : next
      for (const piece of reply.text.match(/[\s\S]{1,8}/g) ?? []) yield { type: 'text', delta: piece }
      yield { type: 'usage', usage: reply.usage ?? { inputTokens: 100, outputTokens: 50 } }
    },
  }
  return { provider, requests, models }
}

import type { RenderResult } from '../render/types'
import { applyEdits, parseReply } from './edits'
import { buildMessages, buildSystemPrompt, formatCompileErrors, type PromptContext } from './prompt'
import { DEFAULT_MAX_TOKENS, type ChatRequest, type ContentPart, type LlmMessage, type LlmProvider, type Usage } from './types'

export interface GenerateResult {
  code: string | null // null when the reply had no usable code
  prose: string
  usage: Usage
  model: string
}

export type TurnEvent =
  | { type: 'delta'; text: string }
  | { type: 'reply'; result: GenerateResult; attempt: number } // attempt 0 = first reply, 1..N = auto-fix
  | { type: 'rendered'; result: RenderResult; attempt: number }
  | { type: 'fixing'; attempt: number; of: number; errors: string }
  | { type: 'gave-up'; attempts: number }

const FIX_REQUEST = 'The code did not compile. Fix the errors above.'

const fullFileRequest = (blockNumber: number) =>
  `SEARCH/REPLACE block ${blockNumber} did not match the current main.scad exactly, so nothing was changed. Reply with the complete updated file in one \`\`\`openscad block.`

async function streamText(
  provider: LlmProvider,
  req: ChatRequest,
  signal: AbortSignal,
  onDelta?: (text: string) => void,
): Promise<{ text: string; usage: Usage }> {
  let text = ''
  let usage: Usage = { inputTokens: 0, outputTokens: 0 }
  for await (const event of provider.streamChat(req, signal)) {
    if (event.type === 'text') {
      text += event.delta
      onDelta?.(event.delta)
    } else {
      usage = event.usage
    }
  }
  return { text, usage }
}

function sumUsage(a: Usage, b: Usage): Usage {
  const reported = a.costUsd !== undefined || b.costUsd !== undefined
  return {
    inputTokens: a.inputTokens + b.inputTokens,
    outputTokens: a.outputTokens + b.outputTokens,
    ...(reported ? { costUsd: (a.costUsd ?? 0) + (b.costUsd ?? 0) } : {}),
  }
}

/** Streams one reply, applies it to baseCode (full file or edits, with one full-file retry when an edit fails). */
export async function generateCode(opts: {
  provider: LlmProvider
  model: string
  history: LlmMessage[]
  userText: string | ContentPart[]
  ctx: PromptContext
  signal: AbortSignal
  onDelta?(text: string): void
  temperature?: number
}): Promise<GenerateResult> {
  const { provider, model, ctx, signal, onDelta, temperature } = opts
  const system = buildSystemPrompt(ctx)
  const messages = buildMessages(opts.history, opts.userText, ctx)
  const request = (msgs: LlmMessage[]): ChatRequest => ({
    model,
    system,
    messages: msgs,
    maxTokens: DEFAULT_MAX_TOKENS,
    ...(temperature !== undefined ? { temperature } : {}),
  })

  const first = await streamText(provider, request(messages), signal, onDelta)
  const parsed = parseReply(first.text)
  if (parsed.kind === 'full') return { code: parsed.code, prose: parsed.prose, usage: first.usage, model }
  if (parsed.kind === 'none') return { code: null, prose: parsed.prose, usage: first.usage, model }

  const applied = applyEdits(ctx.code, parsed.edits)
  if (applied.ok) return { code: applied.code, prose: parsed.prose, usage: first.usage, model }

  const retryMessages: LlmMessage[] = [
    ...messages,
    { role: 'assistant', content: first.text },
    { role: 'user', content: fullFileRequest(applied.failedIndex + 1) },
  ]
  const retry = await streamText(provider, request(retryMessages), signal, onDelta)
  const again = parseReply(retry.text)
  let code: string | null = null
  if (again.kind === 'full') code = again.code
  else if (again.kind === 'edits') {
    const second = applyEdits(ctx.code, again.edits)
    if (second.ok) code = second.code
  }
  return { code, prose: parsed.prose || again.prose, usage: sumUsage(first.usage, retry.usage), model }
}

/** generateCode → render → on failure send the errors back, up to maxFixAttempts. */
export async function runTurn(opts: {
  provider: LlmProvider
  model: string
  history: LlmMessage[]
  userText: string | ContentPart[]
  ctx: PromptContext
  maxFixAttempts: number
  render(code: string, signal: AbortSignal): Promise<RenderResult>
  apply(code: string, source: 'ai' | 'autofix'): void
  onEvent(e: TurnEvent): void
  signal: AbortSignal
}): Promise<void> {
  const { provider, model, ctx, maxFixAttempts, render, apply, onEvent, signal } = opts
  const generate = (history: LlmMessage[], userText: string | ContentPart[], context: PromptContext) =>
    generateCode({ provider, model, history, userText, ctx: context, signal, onDelta: (text) => onEvent({ type: 'delta', text }) })

  let history = opts.history
  let asked: string | ContentPart[] = opts.userText
  let attempt = 0
  let result = await generate(history, asked, ctx)
  onEvent({ type: 'reply', result, attempt })

  for (;;) {
    if (result.code === null) {
      if (attempt > 0) onEvent({ type: 'gave-up', attempts: attempt })
      return
    }
    apply(result.code, attempt === 0 ? 'ai' : 'autofix')
    const rendered = await render(result.code, signal)
    onEvent({ type: 'rendered', result: rendered, attempt })
    if (rendered.ok) return
    if (attempt >= maxFixAttempts) {
      onEvent({ type: 'gave-up', attempts: attempt })
      return
    }
    signal.throwIfAborted()

    const errors = formatCompileErrors(rendered)
    history = [...history, { role: 'user', content: asked }, { role: 'assistant', content: result.prose || 'Updated main.scad.' }]
    asked = FIX_REQUEST
    attempt += 1
    onEvent({ type: 'fixing', attempt, of: maxFixAttempts, errors })
    result = await generate(history, asked, { ...ctx, code: result.code, errors })
    onEvent({ type: 'reply', result, attempt })
  }
}

import { DEFAULT_SETTINGS, type ProviderProfile, type Settings } from '../db/db'
import { deleteProfile, listProfiles, newProfile, saveProfile } from '../db/profiles'
import { getSettings, updateSettings } from '../db/settings'
import type { ProviderPreset } from './presets'

export type ConnectionStatus = 'ok' | 'blocked' | 'failed'
export type ProfilePatch = Partial<Omit<ProviderProfile, 'id' | 'createdAt' | 'updatedAt'>>

export interface ProvidersState {
  loaded: boolean
  profiles: ProviderProfile[]
  settings: Settings
  /** Result of the last Test connection per profile, this session only. */
  status: Record<string, ConnectionStatus>
  load(): Promise<void>
  addProfile(preset: ProviderPreset): Promise<ProviderProfile>
  updateProfile(id: string, patch: ProfilePatch): Promise<void>
  removeProfile(id: string): Promise<void>
  setStatus(id: string, status: ConnectionStatus): void
  chooseModel(profileId: string, model: string): Promise<void>
}

function without(status: Record<string, ConnectionStatus>, id: string): Record<string, ConnectionStatus> {
  const next = { ...status }
  delete next[id]
  return next
}

export const useProvidersStore = create<ProvidersState>()((set, get) => ({
  loaded: false,
  profiles: [],
  settings: DEFAULT_SETTINGS,
  status: {},

  load: async () => {
    try {
      const [profiles, settings] = await Promise.all([listProfiles(), getSettings()])
      set({ profiles, settings, loaded: true })
    } catch {
      // No IndexedDB (some private windows): the app still works by hand, just without saved providers.
      set({ loaded: true })
    }
  },

  addProfile: async (preset) => {
    const profile = await saveProfile(newProfile({ name: preset.name, adapter: preset.adapter, baseUrl: preset.baseUrl }))
    set((s) => ({ profiles: [...s.profiles, profile] }))
    if (get().settings.activeProfileId === null) {
      set({ settings: await updateSettings({ activeProfileId: profile.id, activeModel: null }) })
    }
    return profile
  },

  updateProfile: async (id, patch) => {
    const current = get().profiles.find((p) => p.id === id)
    if (!current) return
    const next: ProviderProfile = { ...current, ...patch, updatedAt: Date.now() }
    set((s) => ({ profiles: s.profiles.map((p) => (p.id === id ? next : p)), status: without(s.status, id) }))
    await saveProfile(next)
  },

  removeProfile: async (id) => {
    await deleteProfile(id)
    const settings = await getSettings()
    set((s) => ({ profiles: s.profiles.filter((p) => p.id !== id), settings, status: without(s.status, id) }))
  },

  setStatus: (id, status) => set((s) => ({ status: { ...s.status, [id]: status } })),

  chooseModel: async (profileId, model) => {
    set((s) => ({ settings: { ...s.settings, activeProfileId: profileId, activeModel: model } }))
    await updateSettings({ activeProfileId: profileId, activeModel: model })
  },
}))

export function selectActiveProfile(s: Pick<ProvidersState, 'profiles' | 'settings'>): ProviderProfile | null {
  return s.profiles.find((p) => p.id === s.settings.activeProfileId) ?? s.profiles[0] ?? null
}

export function selectActiveModel(s: Pick<ProvidersState, 'profiles' | 'settings'>): string | null {
  const profile = selectActiveProfile(s)
  if (!profile) return null
  if (s.settings.activeProfileId === profile.id && s.settings.activeModel) return s.settings.activeModel
  return profile.defaultModel.trim() || null

export interface ChatMessage {
  id: string
  role: 'user' | 'assistant' | 'note'
  text: string
  turnLabel: string | null // "v2" in M2 (session turn number); M3 sets the version label
  model: string | null
  usage: { inputTokens: number; outputTokens: number; cost: number | null } | null
  status: 'streaming' | 'done' | 'error'
  error?: { title: string; body: string }
  compileStatus?: 'ok' | 'error'
  imageBlobIds?: string[] // M5
}

export interface AutoFixState {
  attempt: number
  of: number
  model: string
}

/** The code before the current turn, for "Back to vN" (D6: held in memory in M2). */
export interface BackTo {
  label: string | null
  code: string
}

export interface ChatState {
  messages: ChatMessage[]
  /** What the model has seen: user prompts and reply prose, without code (the code goes in each new request). */
  history: LlmMessage[]
  busy: boolean
  fixing: AutoFixState | null
  backTo: BackTo | null
  turnCount: number
  codeByLabel: Record<string, string>
  /** Composer text; the suggestions fill it. */
  draft: string
  setDraft(text: string): void
  addMessage(m: Omit<ChatMessage, 'id'>): string
  patchMessage(id: string, patch: Partial<Omit<ChatMessage, 'id'>>): void
  appendText(id: string, delta: string): void
  nextLabel(code: string): string
  labelForCode(code: string): string | null
}

export const useChatStore = create<ChatState>()((set, get) => ({
  messages: [],
  history: [],
  busy: false,
  fixing: null,
  backTo: null,
  turnCount: 0,
  codeByLabel: {},
  draft: '',
  setDraft: (draft) => set({ draft }),
  addMessage: (m) => {
    const id = crypto.randomUUID()
    set((s) => ({ messages: [...s.messages, { ...m, id }] }))
    return id
  },
  patchMessage: (id, patch) => set((s) => ({ messages: s.messages.map((m) => (m.id === id ? { ...m, ...patch } : m)) })),
  appendText: (id, delta) => set((s) => ({ messages: s.messages.map((m) => (m.id === id ? { ...m, text: m.text + delta } : m)) })),
  nextLabel: (code) => {
    const n = get().turnCount + 1
    const label = `v${n}`
    set((s) => ({ turnCount: n, codeByLabel: { ...s.codeByLabel, [label]: code } }))
    return label
  },
  labelForCode: (code) => {
    const entries = Object.entries(get().codeByLabel)
    for (let i = entries.length - 1; i >= 0; i--) if (entries[i][1] === code) return entries[i][0]
    return null
  },
}))

/** Total cost of this chat; undefined before any reply, null when no reply had a price. */
export function selectChatCost(s: Pick<ChatState, 'messages'>): number | null | undefined {
  const costs = s.messages.flatMap((m) => (m.role === 'assistant' && m.usage ? [m.usage.cost] : []))
  if (costs.length === 0) return undefined
  const priced = costs.filter((c): c is number => c !== null)
  return priced.length === 0 ? null : priced.reduce((sum, c) => sum + c, 0)
}

```ts
import { computeCost, priceFor } from '../ai/cost'
import { createProvider as defaultCreateProvider } from '../ai/createProvider'
import { describeProviderError } from '../ai/errors'
import { runTurn, type TurnEvent } from '../ai/runTurn'
import type { LlmProvider } from '../ai/types'
import type { ProviderProfile } from '../db/db'
import { addUsage } from '../db/usage'
import { calloutHeadline } from '../editor/diagnosticsExtension'
import { awaitRender } from '../render/awaitRender'
import type { RenderResult } from '../render/types'
import { selectActiveModel, selectActiveProfile, useProvidersStore } from '../settings/providersStore'
import { DEFAULT_CODE, useAppStore } from '../state/store'
import { useChatStore, type ChatMessage } from './chatStore'
import { streamingText } from './streamingText'

export interface SendDeps {
  createProvider?(profile: ProviderProfile): LlmProvider
  render?(code: string, signal: AbortSignal): Promise<RenderResult>
}

let inFlight: AbortController | null = null

export function stopTurn(): void {
  inFlight?.abort()
}

const note = (text: string): Omit<ChatMessage, 'id'> => ({ role: 'note', text, turnLabel: null, model: null, usage: null, status: 'done' })

/** The chat callout for a failed render: the first error line in the editor's words, then OpenSCAD's summary. */
export function compileErrorCallout(result: RenderResult): { title: string; body: string } | undefined {
  if (result.ok) return undefined
  const first = result.diagnostics.find((d) => d.severity === 'error')
  return { title: first ? calloutHeadline(first) : 'The code did not compile', body: result.error }
}

export async function sendPrompt(text: string, deps: SendDeps = {}): Promise<void> {
  const userText = text.trim()
  const chat = useChatStore.getState()
  const providers = useProvidersStore.getState()
  const profile = selectActiveProfile(providers)
  const model = selectActiveModel(providers)
  if (userText === '' || chat.busy || !profile || !model) return

  const startCode = useAppStore.getState().code
  const controller = new AbortController()
  inFlight = controller
  let stoppedByEdit = false
  const unsubscribe = useAppStore.subscribe((s, prev) => {
    if (s.code !== prev.code && s.codeSource === 'manual') {
      stoppedByEdit = true
      controller.abort()
    }
  })

  chat.addMessage({ role: 'user', text: userText, turnLabel: null, model: null, usage: null, status: 'done' })
  const openReply = () => chat.addMessage({ role: 'assistant', text: '', turnLabel: null, model, usage: null, status: 'streaming' })
  let current = openReply()
  useChatStore.setState({ busy: true, fixing: null, draft: '', backTo: { label: chat.labelForCode(startCode), code: startCode } })

  const onEvent = (e: TurnEvent) => {
    const store = useChatStore.getState()
    switch (e.type) {
      case 'delta':
        store.appendText(current, e.text)
        return
      case 'reply': {
        const { result } = e
        const { cost, costSource } = computeCost(result.usage, priceFor(profile, result.model))
        const label = result.code !== null ? store.nextLabel(result.code) : null
        store.patchMessage(current, {
          text: result.prose || (result.code !== null ? 'Updated main.scad.' : 'The reply had no code.'),
          status: 'done',
          turnLabel: label,
          model: result.model,
          usage: { inputTokens: result.usage.inputTokens, outputTokens: result.usage.outputTokens, cost },
        })
        if (e.attempt === 0) {
          useChatStore.setState((s) => ({
            history: [...s.history, { role: 'user', content: userText }, { role: 'assistant', content: result.prose || 'Updated main.scad.' }],
          }))
        }
        void addUsage({
          profileId: profile.id,
          model: result.model,
          inputTokens: result.usage.inputTokens,
          outputTokens: result.usage.outputTokens,
          cost,
          costSource,
        }).catch(() => {
          // A usage row is bookkeeping; never fail the turn over it.
        })
        return
      }
      case 'rendered':
        store.patchMessage(current, { compileStatus: e.result.ok ? 'ok' : 'error', error: compileErrorCallout(e.result) })
        return
      case 'fixing':
        useChatStore.setState({ fixing: { attempt: e.attempt, of: e.of, model } })
        current = openReply()
        return
      case 'gave-up':
        useChatStore.setState({ fixing: null })
        if (e.attempts > 0) {
          store.addMessage(note(`Auto-fix stopped after ${e.attempts} ${e.attempts === 1 ? 'attempt' : 'attempts'}. The code still doesn't compile.`))
        }
        return
    }
  }

  try {
    await runTurn({
      provider: (deps.createProvider ?? defaultCreateProvider)(profile),
      model,
      history: chat.history,
      userText,
      ctx: { code: startCode === DEFAULT_CODE ? '' : startCode },
      maxFixAttempts: providers.settings.autoFixAttempts,
      render: deps.render ?? awaitRender,
      apply: (code, source) => useAppStore.getState().setCode(code, source),
      onEvent,
      signal: controller.signal,
    })
  } catch (err) {
    const store = useChatStore.getState()
    const message = store.messages.find((m) => m.id === current)
    if (controller.signal.aborted) {
      if (message?.status === 'streaming') {
        store.patchMessage(current, { status: 'done', text: streamingText(message.text).prose || 'Stopped before the reply finished.' })
      }
      store.addMessage(note(stoppedByEdit ? 'Stopped: you edited the code.' : 'Stopped.'))
    } else {
      store.patchMessage(current, { status: 'error', text: '', error: describeProviderError(err, profile.baseUrl) })
    }
  } finally {
    unsubscribe()
    if (inFlight === controller) inFlight = null
    useChatStore.setState({ busy: false, fixing: null })
  }
}

/** "Back to vN": stops any running turn and restores the code from before it. */
export function goBack(): void {
  const { backTo, addMessage } = useChatStore.getState()
  if (!backTo) return
  stopTurn()
  useAppStore.getState().setCode(backTo.code, 'restore')
  addMessage(note(`Went back to ${backTo.label ?? 'the code from before this prompt'}.`))
  useChatStore.setState({ backTo: null })
}

  const ids = profile.cachedModels.map((m) => m.id)

  return fallback !== '' && !ids.includes(fallback) ? [fallback, ...ids] : ids

export function ModelPicker() {
  const profiles = useProvidersStore((s) => s.profiles)
  const active = useProvidersStore(selectActiveProfile)
  const model = useProvidersStore(selectActiveModel)
  const chooseModel = useProvidersStore((s) => s.chooseModel)
  const [open, setOpen] = useState(false)
  const [query, setQuery] = useState('')
  const rootRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!open) return
    const onPointerDown = (e: PointerEvent) => {
      if (!rootRef.current?.contains(e.target as Node)) setOpen(false)
    }
    document.addEventListener('pointerdown', onPointerDown)
    return () => document.removeEventListener('pointerdown', onPointerDown)
  }, [open])

  if (profiles.length === 0) {
    return (
      <button type="button" className="pc-model" disabled>
        No model
      </button>
    )
  }

  const typed = query.trim()
  const q = typed.toLowerCase()
  const pick = (profileId: string, id: string) => {
    void chooseModel(profileId, id)
    setOpen(false)
    setQuery('')
  }
  const offerTyped = typed !== '' && active !== null && !modelIds(active).includes(typed)

  return (
    <div
      ref={rootRef}
      className="relative"
      onKeyDown={(e) => {
        if (e.key === 'Escape') setOpen(false)
      }}

        className="pc-model"

              spellCheck={false}

import { selectActiveModel, selectActiveProfile, useProvidersStore } from '../settings/providersStore'
import { IconSend, IconStop } from '../ui/icons'
import { useChatStore } from './chatStore'
import { ModelPicker } from './ModelPicker'
import { sendPrompt, stopTurn } from './sendPrompt'

export function Composer() {
  const draft = useChatStore((s) => s.draft)
  const setDraft = useChatStore((s) => s.setDraft)
  const busy = useChatStore((s) => s.busy)
  const profile = useProvidersStore(selectActiveProfile)
  const model = useProvidersStore(selectActiveModel)

  const blocked = profile === null ? 'Add a provider first' : model === null ? 'Choose a model first' : null
  const canSend = !busy && blocked === null && draft.trim() !== ''
  const send = () => {
    if (canSend) void sendPrompt(draft)
  }

  return (
    <div className="pc-composer">
      <textarea
        rows={2}
        aria-label="Prompt"
        placeholder="Describe a part, or ask for a change"
        value={draft}
        onChange={(e) => setDraft(e.target.value)}
        onKeyDown={(e) => {
          if (e.key === 'Enter' && !e.shiftKey && !e.nativeEvent.isComposing) {
            e.preventDefault()
            send()
          }
        }}
      />
      <div className="pc-composer-bar">
        <ModelPicker />
        <span className="pc-spacer" />
        {busy ? (
          <button type="button" className="pc-btn is-icon is-sm" aria-label="Stop" title="Stop" onClick={stopTurn}>
            <IconStop className="pc-i" aria-hidden="true" />
          </button>
        ) : (
          <button
            type="button"
            className="pc-btn is-icon is-sm is-primary"
            aria-label="Send"
            title={blocked ?? undefined}
            disabled={!canSend}
            onClick={send}
          >
            <IconSend className="pc-i" aria-hidden="true" />
          </button>
        )}
      </div>
    </div>
  )
}

/** Splits `code` spans out of model text as React nodes. Never parses HTML: everything else stays a text node. */
export function inlineCode(text: string): ReactNode[] {
  return text.split(/(`[^`\n]+`)/g).map((part, i) =>
    part.length > 2 && part.startsWith('`') && part.endsWith('`') ? <code key={i}>{part.slice(1, -1)}</code> : part,
  )
}

function MetaLine({ message }: { message: ChatMessage }) {
  const failed = message.compileStatus === 'error'
  const chip = failed ? 'Failed' : message.turnLabel
  const Icon = failed ? IconX : IconSparkle
  return (
    <div className="pc-msg-meta">
      {chip && (
        <span className="pc-chip is-accent">
          <Icon className="pc-i" aria-hidden="true" />
          {chip}
        </span>
      )}
      {message.model && <span>{message.model}</span>}
      {message.usage && (
        <span className="pc-mono" data-testid="msg-cost">

        </span>

export function MessageView({ message }: { message: ChatMessage }) {
  if (message.role === 'note') {
    return (
      <div className="pc-row pc-caption justify-center text-center" data-testid="chat-note">
        {message.text}
      </div>
    )
  }
  if (message.role === 'user') {
    return (
      <div className="pc-msg is-user">
        <div className="pc-msg-body whitespace-pre-wrap">{message.text}</div>
      </div>
    )
  }

  const streaming = message.status === 'streaming'
  const { prose, writing } = streaming ? streamingText(message.text) : { prose: message.text, writing: false }
  return (
    <div className="pc-msg is-assistant" data-testid="chat-reply">
      {prose !== '' && <div className="pc-msg-body whitespace-pre-wrap">{inlineCode(prose)}</div>}
      {streaming ? (

          <IconSpinner className="pc-i motion-safe:animate-spin" aria-hidden="true" />
          {writing ? 'Writing code…' : 'Thinking…'}
        </div>
      ) : (
        message.status === 'done' && <MetaLine message={message} />
      )}
      {message.error && (

            <strong>{message.error.title}</strong>

import { useState } from 'react'
import type { ModelPrice } from '../ai/types'
import type { ProviderProfile } from '../db/db'

const isPrice = (s: string) => s.trim() === '' || (Number.isFinite(Number(s)) && Number(s) >= 0)

function PriceRow({
  model,
  price,
  listed,
  onCommit,
}: {
  model: string
  price?: ModelPrice
  listed?: ModelPrice
  onCommit(price: ModelPrice | null): void
}) {
  const [input, setInput] = useState(price ? String(price.inputPerMTok) : '')
  const [output, setOutput] = useState(price ? String(price.outputPerMTok) : '')
  const commit = () => {
    if (!isPrice(input) || !isPrice(output)) return
    if (input.trim() === '' && output.trim() === '') onCommit(null)
    else onCommit({ inputPerMTok: Number(input || 0), outputPerMTok: Number(output || 0) })
  }
  return (
    <div className="grid grid-cols-[minmax(0,1fr)_120px_120px] items-center gap-2">
      <span className="truncate font-mono text-[13px]">{model}</span>
      <div className={`pc-input is-mono ${isPrice(input) ? '' : 'is-invalid'}`}>
        <input
          aria-label={`${model} input price`}
          inputMode="decimal"
          placeholder={listed ? String(listed.inputPerMTok) : 'Input'}
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onBlur={commit}
        />
        <span className="pc-unit">in</span>
      </div>
      <div className={`pc-input is-mono ${isPrice(output) ? '' : 'is-invalid'}`}>
        <input
          aria-label={`${model} output price`}
          inputMode="decimal"
          placeholder={listed ? String(listed.outputPerMTok) : 'Output'}
          value={output}
          onChange={(e) => setOutput(e.target.value)}
          onBlur={commit}
        />
        <span className="pc-unit">out</span>
      </div>
    </div>
  )
}

export function PriceTable({ profile, onChange }: { profile: ProviderProfile; onChange(table: Record<string, ModelPrice>): void }) {
  const [extra, setExtra] = useState('')
  const ids = [...new Set([profile.defaultModel.trim(), ...Object.keys(profile.priceTable)].filter((id) => id !== ''))]
  const commit = (model: string, price: ModelPrice | null) => {
    const next = { ...profile.priceTable }
    if (price) next[model] = price
    else delete next[model]
    onChange(next)
  }
  const add = () => {
    const id = extra.trim()
    if (id === '') return
    commit(id, profile.priceTable[id] ?? { inputPerMTok: 0, outputPerMTok: 0 })
    setExtra('')
  }
  return (
    <div className="pc-stack" data-testid="price-table">
      <span className="pc-label">Price table</span>
      <span className="pc-caption">US dollars per million tokens, used when the provider doesn't report a cost.</span>
      {ids.map((id) => (
        <PriceRow
          key={id}
          model={id}
          price={profile.priceTable[id]}
          listed={profile.cachedModels.find((m) => m.id === id)?.price}
          onCommit={(price) => commit(id, price)}
        />
      ))}
      <div className="pc-row">
        <div className="pc-input is-mono flex-1">
          <input aria-label="Model to price" placeholder="Model name" value={extra} spellCheck={false} onChange={(e) => setExtra(e.target.value)} />
        </div>
        <button type="button" className="pc-btn is-sm" disabled={extra.trim() === ''} onClick={add}>
          Add model
        </button>
      </div>
    </div>
  )
}

type ChatBody = { model: string; stream?: boolean; max_tokens?: number; messages: Array<{ role: string; content: string }> }

function sse(text: string, usage: Record<string, number>): string {
  const pieces = text.match(/[\s\S]{1,24}/g) ?? []
  const chunks = [...pieces.map((content) => ({ choices: [{ index: 0, delta: { content } }] })), { choices: [], usage }]
  return chunks.map((c) => `data: ${JSON.stringify(c)}\n\n`).join('') + 'data: [DONE]\n\n'
}

/** Serves a fake OpenAI-compatible API. Chat requests get `replies` in order; returns the recorded chat bodies. */
async function fakeLlm(page: Page, replies: string[]): Promise<ChatBody[]> {
  const bodies: ChatBody[] = []
  await page.route(`${BASE}/**`, async (route: Route) => {
    const request = route.request()
    if (request.method() === 'OPTIONS') return route.fulfill({ status: 204, headers: CORS })
    if (request.url().endsWith('/models')) {
      return route.fulfill({
        status: 200,
        headers: { ...CORS, 'content-type': 'application/json' },
        body: JSON.stringify({ data: [{ id: 'fake-model' }] }),
      })
    }
    const body = request.postDataJSON() as ChatBody
    const stream = { ...CORS, 'content-type': 'text/event-stream' }
    if (body.max_tokens === 16) {
      return route.fulfill({ status: 200, headers: stream, body: sse('OK', { prompt_tokens: 5, completion_tokens: 1 }) })
    }
    bodies.push(body)
    const reply = replies.shift() ?? 'No more replies.'
    return route.fulfill({ status: 200, headers: stream, body: sse(reply, { prompt_tokens: 1000, completion_tokens: 310, cost: 0.011 }) })
  })
  return bodies
}

## Contract issues

These are kept exactly as the design doc specifies them; the problems are listed for the design owner.

1. **`ChatRequest.temperature` cannot reach Anthropic.** Current Claude models reject sampling parameters, so the Anthropic adapter never sends `temperature` (or `thinking`). M4's "different temperatures" for variants will only diversify OpenAI-compatible profiles; for Anthropic it needs another source of variety (prompt wording or different models).
2. **`awaitRender` has no way to finish when the editor moves on.** It resolves only for exactly `code`; if the user edits before that render lands, the promise waits until aborted. M2 handles it outside the contract (`sendPrompt` aborts the turn on a manual edit). M3's slider changes during a turn will need the same guard, or `awaitRender` should also reject when `useAppStore.code` changes.
3. **`PromptContext` cannot say "first turn".** `buildSystemPrompt(ctx)` sees only the code, so it cannot choose between "full file" and "SEARCH/REPLACE" instructions; M2 puts that instruction in the final user message, which `buildMessages` builds from the history length. The system prompt describes both formats.
4. **"Every response writes a `usage` row" vs. `GenerateResult.usage`.** When an edit fails and `generateCode` asks for the full file, two provider responses become one `GenerateResult` with summed usage, so M2 writes one row per reply, not per HTTP response. Totals are correct; the row count is not one per request.
5. **`ChatMessage` has no field for what the model saw.** Replies are shown as prose, but the provider history needs user prompts and replies as sent; M2 keeps a separate `chatStore.history: LlmMessage[]`. M3's `StoredMessage` persistence will have to rebuild it from `content` (prose only, as M2 does) or add a field.
6. **No connection status on `ProviderProfile`.** The screen's OK / Blocked pills need the last Test connection result; M2 keeps it in memory (`providersStore.status`), so the pills reset on reload.
7. **`ProviderCapabilities.streaming` only applies to the OpenAI-compatible adapter.** The Anthropic adapter always streams through the SDK.
